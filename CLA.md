## How to sign

No bot runs on this repository. You sign by hand.

1. Read this file.
2. Open your pull request.
3. Write one comment on it with this exact sentence:

   ```
   I have read the CLA of TLD-15 version 1.0, and I accept it.
   ```

4. Sign with the account that owns the commits of that pull request.

One signature covers every later pull request from the same account. A new version of this file asks
for a new signature.
